# Iframe-Test

## Deploy with GitHub Pages

This repository is a static site. To publish it:

1. Commit and push `index.html` to the `main` branch.
2. In the repository on GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Once the deployment finishes, open the URL shown in the Pages settings. It will be `https://mjohntribooohyeah-cell.github.io/Iframe-Test/`.
